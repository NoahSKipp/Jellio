# Service logos

Brand marks for the streaming hub tiles (`js/streamingHub.js`).

## Where these came from

Every SVG here is taken unmodified from [Simple Icons](https://github.com/simple-icons/simple-icons),
whose icon files are released under CC0 1.0 Universal. That licence is
reproduced in `LICENSE.md` beside them.

Most come from 16.28.0. `sky-go.svg` is that release's `sky.svg`, the Sky mark, renamed for the Sky Go tile. Two do not, because that release no longer carries
them: `prime-video.svg` is from 13.21.0 and `hulu.svg` from 9.21.0. Same
project, same licence, older tag.

CC0 covers the files. It does not and cannot cover the marks themselves:
each logo remains the trademark of its owner, used here only to identify
the service a tile links to. That is the ordinary nominative use every
media client makes of them, but it is a use, not a grant.

## Missing on purpose

Prime Video and Hulu were removed from recent Simple Icons releases but are
still in older ones, which is where those two came from. A mark
disappearing from that project usually means its owner asked.

`disney.svg` and `peacock.svg` are in no release of it at all. Those two
come from [Harbor](https://github.com/harborstremio/harbor)
(`public/services/`), an MIT licensed Stremio client, taken unmodified.
Harbor ships them with no attribution and no source note of its own, and
its `disney.svg` carries a `Generated by Pixelmator Pro` comment, so that
one is a hand trace rather than anything official. MIT covers Harbor's
copyright in the file. It does not touch the trademark, which no
downstream licence can grant.

`amc.svg`, `shudder.svg` and `discovery.svg` (AMC+, Shudder, Discovery+) are
in neither project. They come from [Custom Brand Icons](https://github.com/elax46/custom-brand-icons)
by Emanuele & rchiileea, version 1.2.65 as packaged in `@iconify-json/cbi`
(icons `amc`, `shudder`, `discovery-plus`), with only an `<svg>` wrapper
added around each icon body. Those three files, unlike the rest of this
folder, are licensed [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/):
attribution, non-commercial use only, and adaptations under the same terms.
Jellio is non-commercial; anyone redistributing it commercially has to drop
or replace them.

Tiles without a logo fall back to the service name set in type, so the strip
works either way.

## Adding one

Drop `<slug>.svg` in this folder, where the slug is the service name
lowercased with non-alphanumerics collapsed to a single hyphen:

| Service | File |
| --- | --- |
| Disney+ | `disney.svg` |
| Prime Video | `prime-video.svg` |
| Peacock | `peacock.svg` |
| AMC+ | `amc.svg` |
| Shudder | `shudder.svg` |
| Discovery+ | `discovery.svg` |
| Sky Go | `sky-go.svg` |

`Frontend\**\*` in the csproj embeds the folder, so a new file needs no
build change. It must be monochrome: the tiles force it white with a CSS
filter rather than trusting whatever fill the file ships with.
