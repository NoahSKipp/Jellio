Ani-Sync (Per-User Anime & Manga Tracking)

Setting OAuth Client IDs and Secrets here lets every user connect their own AniList, MyAnimeList, Shikimori, or Simkl account with one click. All watched/read progress still syncs strictly to each user's own account, and fields left blank can still be entered by individual users.
Create an API client at anilist.co/settings/developer with redirect URL https://anilist.co/api/v2/oauth/pin and paste its ID here.
Optional default MyAnimeList OAuth Client ID for user Ani-Sync login and token refresh.
Paired with the Simkl Client ID under Playback & Live TV when using Simkl Ani-Sync.

Books & Manga Services

Optional self-hosted integrations for book requests, in-reader translation, and manga sources. Books and audiobooks themselves need no setup here: add a Jellyfin library of type Books and Jellio reads and plays it natively.

Chaptarr (Book Requests)

Must be reachable from the Jellyfin server.
From Chaptarr Settings > General.

DeepL (Book Reader Translation)

Powers Translate in the book reader's selection popup. Free keys (ending in :fx) from deepl.com/pro-api give 500,000 chars/month.
