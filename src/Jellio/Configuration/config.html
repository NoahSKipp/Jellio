Calendar

Powers the Coming Soon row and the Calendar page: upcoming episode air dates and movie digital release dates for whatever is on a user's own Watchlist, read straight off each item's own ProviderIds.Tmdb (every Gelato import already carries one). Needs a free TMDB API Read Access Token, from themoviedb.org under Settings > API, the long token, not the short v3 key. Left blank, both the row and the page just stay empty, nothing else is affected.

Skip Intro/Credits

Real community timestamp databases, tried before this plugin's own cross-episode audio analysis: no stream or ffmpeg access needed, so a title gets a real Skip Intro/Credits button the very first time it is opened. TheIntroDB (theintrodb.org) covers general TV/movies and already works anonymously straight off this item's own TMDB id, no key required. An optional API key from TheIntroDB's own website just weights a reader's own submissions higher. SkipMe.db is a second, independently crowdsourced general TV/movie database on the same TMDB id, but its public endpoint currently rejects every request without a private credential this plugin cannot obtain - left off below until that changes, since leaving it on today would only add a guaranteed-failed lookup to every scan. IntroDB (introdb.app) adds a third TV-specific database, keyed by IMDb id instead - it needs the TMDB Access Token above configured to resolve one first, and an optional API key from its own website works the same graceful-blank way TheIntroDB's does. AniSkip and Anime-Skip (the same approach NuvioTV itself uses) cover anime specifically, whatever none of the three above have: a free Simkl client ID (simkl.com, under Settings > Developer) maps a title onto the MyAnimeList/AniList id they key off, and a separate free Anime-Skip client ID (anime-skip.com) adds its own fallback coverage for whatever AniSkip alone does not have. Any of these left blank, that one piece is skipped and everything else keeps working as before.

Announcements

Sends a one time message to every user on this server (a restart, planned maintenance, anything worth a heads up). Delivered as a toast to anyone with Jellio open, and left sitting in everyone's own Notifications either way.
