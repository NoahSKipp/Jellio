Seasonal Themes

Applies to every user on this server. Reskins the whole page (background wash, badge and focus colors, a themed ambient layer sitting behind the real content rather than over it) to match whichever of these four occasions is active today, one at a time. Never shown during playback. Each one has its own Start/End date so it can run for a single day or stretch across a whole week; per user overrides may come later, for now this is the one shared, server wide switch.

Calendar

Powers the Coming Soon row and the Calendar page: upcoming episode air dates and movie digital release dates for whatever is on a user's own Watchlist, read straight off each item's own ProviderIds.Tmdb (every Gelato import already carries one). Needs a free TMDB API Read Access Token, from themoviedb.org under Settings > API, the long token, not the short v3 key. Left blank, both the row and the page just stay empty, nothing else is affected.
